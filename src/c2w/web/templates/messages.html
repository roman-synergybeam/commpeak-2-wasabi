About delivery status

Sent means the carrier accepted the message; delivered means a handset confirmed it. The gap between the two is where messages go missing, so they are shown separately rather than merged. Receipts can arrive hours later, so a recent message showing not yet is normal — each poll re-reads a window of recent history, set under Settings → CommPeak SMS, so a late confirmation is picked up rather than left wrong for ever.
